基本情報ドリルについて

「基本情報ドリル」は、基本情報技術者試験（FE）の学習用の無料アプリです。広告、アプリ内課金、ログインはありません。通信を行わないため、機内モードやオフラインでも使えます。

  • 問題演習：オリジナル問題 340 問（科目A 300 問、科目B 40 問）と、IPA の公開問題・サンプル問題 165 問
  • 復習：解いた問題を、正誤に応じて間隔をあけて再び出題します
  • カード：用語 300 語を、カードを左右にスワイプして覚えます
  • 模試：途中で中断して、あとから再開できます
  • 学習リマインダー：毎日決まった時刻に通知します（任意）

Web 版もあります：https://kohkim1106-a11y.github.io/fe-drill/

よくある質問

学習記録を別の端末に引き継げますか

現在のバージョンには、記録を別の端末へ引き継ぐ機能はありません。学習記録はその端末の中にだけ保存されます。iPhone アプリと Web 版の記録も別々です。

学習記録をリセットしたい

「分析」タブから設定画面を開き、「学習記録のリセット」で、回答の記録・復習の予定・日ごとの記録を消せます。消した記録は元に戻せません。アプリを削除した場合も記録は消えます。

リマインダーの通知が来ない

  • アプリの設定画面（「分析」タブから開きます）の「学習リマインダー」で「毎日通知する」がオンになっているか、時刻が正しいかを確認してください。
  • iPhone の「設定」→「通知」→「基本情報ドリル」で通知が許可されているかを確認してください。
  • 集中モードやおやすみモードがオンのときは、通知が表示されないことがあります。

問題や解説の誤りを見つけた

問題の画面にある「誤りを報告」を押すと、その問題の ID が表示されます。「コピー」で ID をコピーし、どこが誤っているかを添えて GitHub の Issues に書き込んでください。アプリから自動で送信されることはありません。

問い合わせ

不具合の報告や要望は、GitHub の Issues で受け付けています。

https://github.com/kohkim1106-a11y/fe-drill/issues

Issues は公開されます。個人情報は書き込まないでください。

出典・ライセンス表記

本アプリの一部の問題は、独立行政法人情報処理推進機構（IPA）が公開している基本情報技術者試験の公開問題・サンプル問題を出典としています。各問題に出典（年度・試験区分・問番号）を記載し、図表を文章に改めるなど一部を改変した問題にはその旨を付記しています。解説は本アプリ独自のものであり、IPA が作成したものではありません。問題の著作権は IPA に帰属します。

オリジナル問題と用語の解説は、本アプリのために作成したものです。

IPA の過去問題の利用条件：IPA「よくある質問（試験）」

プライバシー

本アプリは個人情報や利用状況を収集しません。詳しくはプライバシーポリシーをご覧ください。
