# 要件定義書 — 基本情報ドリル

最終更新: 2026-10-24 / 版: 1.0（ヒアリング結果を反映）

## 1. 目的

基本情報技術者試験（FE）に 1〜3 か月後に合格するため、スマホのすきま時間で科目A・科目Bの両方を効率よく学習できるアプリを作る。

## 2. 利用者と利用シーン

| 項目 | 内容 |
|---|---|
| 利用者 | 本人（KOKI）。将来ほかの受験者に共有する可能性あり |
| 主な端末 | スマホ（iPhone Safari を想定）。補助で Mac のブラウザ |
| 利用シーン | 通勤・休憩中に5〜15分。机ではPCで模試 |

## 3. ヒアリング結果

| 質問 | 回答 |
|---|---|
| 利用環境 | スマホ中心（PWA） |

| 問題の出所 | AIオリジナル問題 ＋ IPA公開の過去問・サンプル問題（ダウンロード可） |
| 欲しい機能 | 用語暗記カード／試験日までの学習計画／端末間の記録同期／苦手分析・間隔反復 |
| 同期方式 | Firebase（無料枠）。プロジェクト作成は本人が後で行う |

| 保存先 | ~/Desktop/fe-drill |

## 4. 機能要件

### F1 演習
- F1-1 科目A：四肢択一（ア〜エ）。選択肢は毎回シャッフル。解答後に正誤と解説を表示
- F1-2 科目B：擬似言語のトレース問題、情報セキュリティの事例問題。コードは等幅・横スクロールで表示
- F1-3 演習モード：ランダム10問／分野別（シラバスの大分類・中分類）／弱点復習／基数変換ドリル（自動生成）
- F1-4 模試：ミニ模試（20問・30分）、本番形式の科目A（60問・90分）、科目B（20問・100分）。途中で中断・再開できる
- F1-5 出典表示：IPA問題は「令和○年度 科目A 問○」のように出典を表示

### F2 問題データ
- F2-1 問題は JSON で管理し、スキーマで検証する（必須項目・正解番号の範囲・ID重複）
- F2-2 初期収録の目標：AIオリジナル 科目A 300問・科目B 40問、IPA公開問題（取得できる範囲で）
- F2-3 各問題にシラバスの分類（大分類／中分類）と難易度を持たせる

### F3 用語暗記カード
- 用語と意味をめくって覚える。「覚えた／まだ」で自己評価。目標 300語
- 分野で絞り込める

### F4 苦手分析・間隔反復
- F4-1 問題・用語カードごとに次回出題日を持つ（SM-2 を簡略化した方式）
- F4-2 「今日の復習」に期限が来た問題をまとめて出す
- F4-3 分野別の正答率と、正答率の低い中分類トップ5を表示

### F5 学習計画
- 試験日を入力すると、残り日数・1日の目標問題数・達成状況を表示
- 直近14日の学習量をグラフで表示

### F6 端末間同期
- Firebase Authentication（Googleログイン）＋ Cloud Firestore で学習記録を同期
- Firebase の設定がない／未ログインでもすべての機能がローカルで動く
- オフライン中の記録は、オンライン復帰時に同期する。競合は「新しい更新を優先」で解決

### F7 PWA
- ホーム画面に追加でき、オフラインでも演習できる
- 新しい版が出たら「更新があります」と表示する

## 5. 非機能要件

| 区分 | 要件 |
|---|---|
| 対応環境 | iOS Safari 17 以降、Chrome／Edge 最新版。幅 360px〜 |
| 性能 | 4G 回線で初回表示 3 秒以内、2回目以降はオフラインで即表示 |
| 使いやすさ | 片手で操作できる（主要ボタンは画面下部、タップ領域 44px 以上）。ダークモード対応 |
| アクセシビリティ | キーボード操作、フォーカス表示、スクリーンリーダー向けのラベル |
| セキュリティ | Firestore ルールで本人のデータだけ読み書き可。秘密情報をリポジトリに置かない |
| 保守性 | TypeScript、自動テスト（単体・画面操作）、問題データの自動検証 |
| コスト | すべて無料枠で運用 |

## 6. 対象外（今回はやらない）

- 複数人のランキング・SNS共有、課金、ネイティブアプリ
- AIによるその場の解説生成（将来検討）

- IPAの過去問題は、IPAの利用条件に従い出典を明記して収録する。製造前に最新の利用条件を確認する
- Firebase プロジェクトの作成と設定値の貼り付けは本人が行う（手順書を用意する）
- GitHub へのログイン（`gh auth login`）は本人が行う
