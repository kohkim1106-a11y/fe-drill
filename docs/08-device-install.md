# 自分のiPhoneで試す方法

3つの方法があります。上ほど手軽で、下ほど本番（App Store版）に近くなります。

| 方法 | 費用 | 準備 | 有効期間 | 通知リマインダー |
|---|---|---|---|---|
| A. Web版をホーム画面に追加 | 無料 | なし | ずっと | 使えない |
| B. Xcodeから直接インストール | 無料（Apple IDのみ） | Mac・ケーブル | 7日（再インストールで延長） | 使える |
| C. TestFlight | Apple Developer Program（年99ドル） | 登録の承認 | 90日 | 使える |

## A. Web版をホーム画面に追加（今すぐできる）

1. iPhoneのSafariで https://kohkim1106-a11y.github.io/fe-drill/ を開く
2. 下の共有ボタン（四角から上矢印）→「ホーム画面に追加」→「追加」
3. ホーム画面のアイコンから起動すると、アプリと同じ全画面で動きます。一度開けば機内モードでも使えます

注意：学習記録はSafariのホーム画面アプリごとに保存されます。B・Cのアプリ版とは共有されません。

## B. Xcodeから直接インストール（無料、ネイティブ版）

【本人のみ】と書いた手順は、Apple IDのサインインなどご本人の操作が必要です。

1. 【本人のみ】iPhoneをケーブルでMacにつなぎ、iPhoneに「このコンピュータを信頼しますか？」と出たら「信頼」
2. 【本人のみ】iPhoneの「設定」→「プライバシーとセキュリティ」→「デベロッパモード」をオンにして再起動
   （項目が見当たらないときは、先に手順4まで進めると表示されます）
3. Macのターミナルでアプリを最新にしてXcodeを開く
   ```bash
   cd ~/Developer/fe-drill && npm run ios
   ```
4. 【本人のみ】Xcodeの「Xcode」メニュー →「Settings…」→「Accounts」→「＋」→「Apple Account」で自分のApple IDを追加
5. 左の一覧で「App」→ TARGETS の「App」→「Signing & Capabilities」タブ
   - 「Automatically manage signing」にチェック
   - Team で「（自分の名前）(Personal Team)」を選ぶ
   - 「Bundle Identifier は使えません」と出たら、末尾に `.dev` を付けて `com.kohki.m1106.dev` にする（App Store提出時は元に戻す）
6. 画面上部の実行先で、つないだiPhoneを選び、▶（Run）を押す
7. 【本人のみ】初回はiPhoneで「信頼されていないデベロッパ」と出るので、「設定」→「一般」→「VPNとデバイス管理」→ 自分のApple ID →「信頼」。もう一度アイコンから起動

無料のPersonal Teamで入れたアプリは7日で起動できなくなります。続けて使うときは、手順6をもう一度行うと7日延びます（学習記録は消えません）。

## C. TestFlight（App Store提出前の最終確認）

Apple Developer Programの登録が承認されたら、[07-ios-release.md](07-ios-release.md) の手順5・6で配信します。7日の期限がなく、通知や機内モードでの起動など本番と同じ状態で確認できます。

## 実機で確認したいこと

- [ ] 機内モードで起動し、演習・カードが動く
- [ ] 設定で学習リマインダーをオンにし、指定時刻に通知が届く
- [ ] カードの左右スワイプ、解説パネルの上スワイプ
- [ ] ダーク・ライトの切り替え（ホーム右上の歯車 → 設定）
- [ ] ふりがなの表示（設定 → 表示）
