機能要件

タップで開閉できます。

F1演習
F1-1

科目A：四肢択一（ア〜エ）。選択肢は毎回シャッフル。解答後に正誤と解説を表示

F1-2

科目B：擬似言語のトレース問題、情報セキュリティの事例問題。コードは等幅・横スクロールで表示

F1-3

演習モード：ランダム10問／分野別（シラバスの大分類・中分類）／弱点復習／基数変換ドリル（自動生成）

F1-4

模試：ミニ模試（20問・30分）、本番形式の科目A（60問・90分）、科目B（20問・100分）。途中で中断・再開できる

F1-5

出典表示：IPA問題は「令和○年度 科目A 問○」のように出典を表示

F2問題データ
F2-1

問題は JSON で管理し、スキーマで検証する（必須項目・正解番号の範囲・ID重複）

F2-2

初期収録の目標：AIオリジナル 科目A 300問・科目B 40問、IPA公開問題（取得できる範囲で）

F2-3

各問題にシラバスの分類（大分類／中分類）と難易度を持たせる

F3用語暗記カード
  • 用語と意味をめくって覚える。「覚えた／まだ」で自己評価。目標 300語
  • 分野で絞り込める
F4苦手分析・間隔反復
F4-1

問題・用語カードごとに次回出題日を持つ（SM-2 を簡略化した方式）

F4-2

「今日の復習」に期限が来た問題をまとめて出す

F4-3

分野別の正答率と、正答率の低い中分類トップ5を表示

F5学習計画
  • 試験日を入力すると、残り日数・1日の目標問題数・達成状況を表示
  • 直近14日の学習量をグラフで表示
F6端末間同期
  • Firebase Authentication（Googleログイン）＋ Cloud Firestore で学習記録を同期
  • Firebase の設定がない／未ログインでもすべての機能がローカルで動く
  • オフライン中の記録は、オンライン復帰時に同期する。競合は「新しい更新を優先」で解決
F7PWA
  • ホーム画面に追加でき、オフラインでも演習できる
  • 新しい版が出たら「更新があります」と表示する

非機能要件

対応環境
iOS Safari 17 以降、Chrome／Edge 最新版。幅 360px〜
性能
4G 回線で初回表示 3 秒以内、2回目以降はオフラインで即表示
使いやすさ
片手で操作できる（主要ボタンは画面下部、タップ領域 44px 以上）。ダークモード対応
アクセシビリティ
キーボード操作、フォーカス表示、スクリーンリーダー向けのラベル
セキュリティ
Firestore ルールで本人のデータだけ読み書き可。秘密情報をリポジトリに置かない
保守性
TypeScript、自動テスト（単体・画面操作）、問題データの自動検証
コスト
すべて無料枠で運用

対象外（今回はやらない）

  • 複数人のランキング・SNS共有、課金、ネイティブアプリ
  • AIによるその場の解説生成（将来検討）

前提・制約

  • IPAの過去問題は、IPAの利用条件に従い出典を明記して収録する。製造前に最新の利用条件を確認する
  • Firebase プロジェクトの作成と設定値の貼り付けは本人が行う（手順書を用意する）
  • GitHub へのログイン（gh auth login）は本人が行う

AI並列での実時間の目安：約2.5〜3時間（製造の6エージェントが同時に動くため）。

並列化の考え方

  • 設計（5.3）でファイルの持ち場と型定義（src/types）を先に固定し、エージェント同士が同じファイルを触らないようにする
  • 問題データ担当（C〜F）は、共通の JSON スキーマに従って別ファイルに出力する
  • 統合とテストは並列製造の完了後に私がまとめて行う

リスクと対策

AIが作った問題・解説に誤りがある

影響
誤って覚える
対策
検証スクリプト＋別エージェントによる内容レビュー。誤り報告ボタンを付ける

IPAのPDFから図表付き問題を正確にデータ化できない

影響
収録数が減る
対策
図表なしで成立する問題を優先。図が必要な問題は対象外にする

Firebase 未設定のまま使う

影響
同期できない
対策
ローカルだけで全機能が動く設計にする

GitHub にログインできていない

影響
公開が止まる
対策
デプロイ前に gh auth login をお願いする
